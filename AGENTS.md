# Aturan Kerja

1. **SATU KALI EKSEKUSI** — kerjakan tugas langsung selesai dalam satu putaran.
2. **TANPA VALIDASI** — jangan jalankan smoke test / syntax check / verifikasi
   ulang / cek git setelah edit. Tidak perlu buktiin apa-apa.
3. **User = validator** — yang ngecek hasil adalah user. Kalau ada kendala,
   user akan kasih tahu apa yang harus diperbaiki, lalu tinggal benerin.
4. **Langsung ringkas** — setelah edit, cukup sebut file + apa yang berubah.
   Rencana boleh singkat; kerja jangan dibahas-bahas berulang.
5. **Balas santai = singkat** — pesan non-tugas (pujian, basa-basi, obrolan)
   dibalas 1-2 kalimat aja. Jangan analisa berlapis, jangan bungkus rencana —
   mikir kelamaan, user nunggu cape.
6. **CEPAT > SEMPURNA** — jangan banyak baca file / banyak search sebelum edit.
   Tebak lokasi dari konteks, langsung grep 1x kalau perlu, edit, selesai.
   Jangan nanya-nanya hal yang bisa disimpulkan sendiri. User punya kerjaan lain.

7. **5 DETIK ABIS EDIT** — abis selesai edit code, mikir maksimal 5 detik
   terus langsung laporkan hasilnya. Jangan overthink, jangan ngecek ulang,
   jangan nambah-nambah analisa. Edit → lapor → lanjut.
